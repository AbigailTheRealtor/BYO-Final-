# Spatial / Location DNA CI inventory
#
# The explicit, reviewed list of PHPUnit FILES that the "Spatial / Location DNA Tests"
# workflow (.github/workflows/spatial-location-dna-tests.yml) executes.
#
# WHY A COMMITTED MANIFEST RATHER THAN A GLOB
# -------------------------------------------
# This suite was previously reconstructed ad hoc with a path regex along the lines of
# `LocationDna|Location|Place|Spatial|...`. That is not a definition of the suite, it is a
# string match on filenames, and it quietly swept in tests that have nothing to do with
# geography because an unrelated word contains a matching substring:
#
#   PropertyTypePlaceholderHelperTest        "Place"  inside "Placeholder"
#   BatchFourAgentCredentialsPlaceholderTest "Place"  inside "Placeholder"
#   MlsImportEntryPointTest                  "Poi"    inside "EntryPoint"
#
# All three assert UI copy or modal routing and contain no spatial logic; the first was red
# on main for reasons no spatial change could ever fix. A regex cannot tell those apart from
# real POI and place tests, so the membership rule is a reviewed file list instead. Adding a
# spatial test means adding its line here, in a diff someone reads.
#
# The inverse case is why membership is decided by SUBSTANCE, not by the filename:
# DatabaseGuardPoisoningTest also matches only incidentally ("Poi" inside "Poisoning"), but
# it proves TestCase::assertSafeTestDatabase() actually aborts the run — the isolation this
# entire suite depends on — so it is listed deliberately.
#
# FORMAT
#   * one repository-relative *Test.php path per line
#   * `#` comments and blank lines are ignored by the runner
#   * ordering is deterministic (LC_ALL=C sort) so the diff of an edit is legible
#   * no globs, no directory entries, no wildcards
#
# The workflow fails if any listed path does not exist, so a renamed or deleted file cannot
# silently drop out of the gate. Every file is run in its OWN phpunit invocation: PHPUnit 9
# accepts one test target from the command line and SILENTLY IGNORES additional paths, so
# `phpunit a.php b.php` runs only a.php and still exits 0 (the same false-green documented in
# .github/workflows/migration-tests.yml).
#
# Known, deliberate environment-dependent skips are documented in the workflow.
